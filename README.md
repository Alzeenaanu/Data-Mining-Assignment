# Data Preprocessing and Decision Tree Classification

## Objective
To implement a complete data mining pipeline including preprocessing, feature selection, decision tree classification, and evaluation.

## Dataset
The dataset contains 100 student records with the following attributes:
- Age
- Study_Hours
- Attendance
- Internal_Marks
- Result (Pass/Fail)

## Steps Implemented
1. Data loading and exploration
2. Data preprocessing (handling missing values, normalization, encoding)
3. Feature selection using Gini Index
4. Decision Tree model training
5. Model evaluation (Accuracy, Precision, Recall, F1-score)

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
